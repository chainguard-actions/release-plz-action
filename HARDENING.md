## Findings Fixed

### script-injection (severity: high)

Sub-rule (a): The 'Install release-plz' run: block directly interpolates ${{ inputs.version }} into a shell command string: `cargo-binstall release-plz@${{ inputs.version }}`. An attacker-controlled value for `inputs.version` is expanded by the GitHub Actions template engine before the shell ever sees it, enabling arbitrary command injection (e.g. a value like `0.3.169 --no-confirm; malicious-command` would be executed verbatim).
